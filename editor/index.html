코스 좌표 편집기

위성지도에서 홀별 티박스·그린을 찍어 앱용 코스 파일(v2)을 만듭니다.

골프장

홀

지도를 클릭하면 선택한 항목(티박스/그린) 위치가 들어갑니다. 마커는 끌어서 옮기고, 우클릭(길게 누르기)하면 지웁니다.

라운드 기록 겹쳐보기

앱이 Drive(GolfApp_Records)에 저장한 라운드 .json 을 열면 티샷·홀컵 위치가 홀 번호와 함께 지도에 표시됩니다. 홀 번호를 맞추는 데 쓰세요.

점검

내보내기

저장한 파일을 폰으로 보내 앱의 골프장 찾기 → 📂 코스 파일 가져오기로 넣으면 바로 씁니다. 공개 데이터에 올리려면 course-data/courses/에 넣고 python3 tools/course_data.py index를 실행하세요.

지도

확대: 트랙패드 핀치·마우스 휠·+ 버튼 (더블클릭은 점 찍기라 확대 안 됨). Esri 사진이 흐리면 오른쪽 위에서 Esri Clarity로 바꿔 보세요. 국내는 VWorld 항공사진이 가장 선명합니다 — vworld.kr 회원가입 → 오픈API → 인증키 발급(서비스 URL에 https://wannawork.github.io) 후 위 칸에 붙여넣기.
공개 배포할 좌표는 Esri/VWorld 사진이나 직접 간 기록으로 찍으세요(구글·카카오·네이버 지도에서 좌표를 따내 공개하는 건 각 약관상 제한됩니다).
